# 가계부 사용법

내 자산과 월별 지출/입금을 한 화면에서 관리하고, 금액을 입력하면
총 자산·월별 총지출·총수입·남은 금액이 자동으로 계산되는 개인 가계부입니다.

## 파일 구성

```
index.html   화면 구조
style.css    디자인/레이아웃
script.js    입력, 계산, 저장 로직
README.md    이 문서
```

세 파일을 **같은 폴더**에 넣어두세요. `index.html`이 `style.css`와
`script.js`를 상대 경로로 불러오기 때문에, 폴더째로 옮기거나
압축해서 옮겨도 그대로 동작합니다.

## 실행 방법

`index.html` 파일을 더블클릭해서 브라우저(크롬, 사파리, 엣지 등)로 열면 바로 사용할 수 있습니다.
별도의 서버나 설치 과정이 필요 없습니다.

## 화면 구성과 사용법

### 1. 내 자산
- 토스(기본 298,000원), 카카오뱅크, 세이프뱅크, 주식, KB국민은행, 농협 등 등록된 자산의 기본 잔액을 관리합니다.
- **자산 추가 (`+`)**: 우측 상단의 `+ 자산 추가` 버튼을 눌러 새로운 통장이나 계좌, 자산 항목을 추가할 수 있습니다.
- **자산 삭제 (`−`)**: 각 자산 카드 우측 상단의 `−` 버튼을 눌러 사용하지 않는 자산 항목을 삭제할 수 있습니다.
- **입금 실시간 누적 합산 (`+`)**: 입금 내역에 금액을 입력하면, 기존 자산 금액이 초기화되지 않고 **기존 기본 잔액 + 이번 달 입금액**이 더해져 각 자산 카드와 총 자산에 즉시 반영됩니다.

### 2. 월별 내역
상단의 `9월 / 10월 / 11월 / 12월 / 1월 / 2월` 탭을 눌러 달을 선택합니다.

- **입금 내역**: 각 항목별 입금 계좌가 지정되어 내 자산과 실시간 연동됩니다.
  - **월급, 토스로 계좌이체, 용돈, 기타**: `토스` 입금 (내 자산의 토스 기존 금액 298,000원에 **`+` 합산**)
  - **국취제 훈련자금**: `KB국민은행` 입금 (내 자산의 KB국민은행 기존 금액에 **`+` 합산**)
  - 금액을 입력하면 **○월 총수입**이 자동 계산됩니다.
- **지출 내역**: 현대카드 할부·결제, 식비, 교통비, 미용비, PC방, 취미, 월세, 관리비, 통신비, 생활용품, 기타 등 모든 지출은 **`토스` 계좌에서 출금** 처리되며 **○월 총지출**이 자동 계산됩니다.

탭을 바꿔가며 6개월 각각의 입금·지출을 따로 입력할 수 있습니다.

### 3. 요약
모든 달을 합친 결과를 보여줍니다.

- **총 자산**: 각 자산의 실제 잔액(기본 잔액 + 이번 달 입금)의 총합
- **전체 수입 (9월–2월)**: 6개월치 입금 합계
- **전체 지출 (9월–2월)**: 6개월치 지출 합계
- **남은 금액** = 총 자산 + 전체 수입 − 전체 지출

하단에는 주요 입출금 계좌의 **잔액 카드**가 함께 제공됩니다:

- **토스 예상 잔액**:
  ```
  토스 총잔액(기존 298,000원 + 이번 달 토스 입금 합계) − 이번 달 총지출
  ```
- **KB국민은행 잔액**:
  ```
  KB국민은행 총잔액(기존 잔액 + 이번 달 국취제 훈련자금)
  ```

즉, 현재 선택한 달을 기준으로 수입/지출 후 각 계좌에 실제로 남게 될 예상 잔액을 직관적으로 확인할 수 있습니다.

## 계산식(수식) 입력

금액 칸에는 숫자뿐 아니라 엑셀처럼 계산식을 입력할 수 있습니다.

| 입력 | 결과 |
|---|---|
| `217870+30000-10000` | ₩237,870 |
| `30000*2` | ₩60,000 |
| `(100000+50000)-20000` | ₩130,000 |

칸에 입력한 뒤 **Enter를 누르거나 다른 칸을 클릭(포커스 아웃)** 하면 자동으로 계산되어
`237,870원` 형태로 표시됩니다. 다시 그 칸을 클릭하면 방금 입력했던 계산식이 그대로
나타나서 수정하기 편합니다. 계산식 밑에 작게 `= 217870+30000-10000` 처럼 원래 수식도
같이 표시됩니다.

`+ - * / ( )` 와 숫자, 소수점만 입력할 수 있으며, 잘못된 수식을 입력하면 칸 테두리가
빨갛게 깜빡이며 이전 값으로 되돌아갑니다.

## 자동 저장

모든 입력값은 브라우저의 **로컬 저장소(localStorage)** 에 저장됩니다.

- 새로고침하거나 창을 닫았다가 다시 열어도 값이 그대로 유지됩니다.
- 저장된 데이터는 이 브라우저(이 컴퓨터의 이 폴더에서 연 페이지)에만 남고,
  다른 기기나 다른 브라우저와는 공유되지 않습니다.
- 우측 상단 **초기화** 버튼을 누르면 확인창이 뜨고, 확인하면 모든 자산·수입·지출 데이터가
  초기 상태로 리셋됩니다. (되돌릴 수 없으니 신중히 눌러주세요.)

## 다크 모드

우측 상단의 🌙/☀ 버튼으로 라이트/다크 테마를 전환할 수 있습니다. 선택한 테마도
브라우저에 저장되어 다음에 열 때도 유지됩니다.

## 참고

- 금액은 항상 원화(₩) 형식으로 표시됩니다.
- 인터넷 연결이 끊겨도 폰트만 기본 서체로 바뀔 뿐, 입력·계산·저장 기능은 그대로 동작합니다.
- 다른 사람과 공유하고 싶다면 `index.html`, `style.css`, `script.js` 세 파일을 통째로
  전달하면 됩니다 (README.md는 사용법 설명용이라 없어도 앱은 동작합니다).
